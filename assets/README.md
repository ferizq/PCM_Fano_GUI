This folder should contain local copies of Plotly and KaTeX if you want the GUI to run fully offline.

Files to place here (examples / suggested names):
- `plotly.min.js`  — Plotly JavaScript bundle (e.g. `plotly-latest.min.js`).
- `katex.min.css`
- `katex.min.js`
- `auto-render.min.js`

If these are not present, the GUI will fallback to CDN-hosted assets.

To download Plotly for offline use, visit https://plotly.com/javascript/ and save the `plotly.min.js` bundle.
For KaTeX assets, use the official CDN links and save the corresponding files locally.
